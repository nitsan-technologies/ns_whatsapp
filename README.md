## Features

- WhatsApp chat button (Style 1)
- Phone number and pre-filled message configuration
- Position, mobile/desktop visibility, and hide-on-pages controls
- Basic button color and text customization in the backend
- Compatible with TYPO3 v12, v13, and v14 (Site Sets)
